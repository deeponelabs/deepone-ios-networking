# DeepOneNetworking - Networking Framework

This framework is distributed as a pre-compiled XCFramework for:
- **Performance**: Optimized binary reduces build times
- **Security**: Source code protection
- **Compatibility**: Supports iOS, iPadOS, and Mac Catalyst
- **Size**: Minimal footprint with dead code elimination

## 🔗 **Usage**

> **Note:** This is a low-level core-networking framework. For a complete SDK with high-level APIs, 
> use [DeepOneSDK](https://github.com/deeponelabs/deepone-ios-sdk) instead.

```swift
import DeepOneNetworking

// Core framework provides low-level networking and attribution APIs
// Developers should use the higher-level DeepOneSDK instead
```
